# Publication Checklist

Before using runs as confirmatory H4 evidence:

- [ ] Freeze and deposit the preregistration.
- [ ] Record the protocol DOI / repository identifier.
- [ ] Freeze the I-1 manifest and record its SHA-256 hash.
- [ ] Tag the repository release used for the runs.
- [ ] Record Docker and Compose versions.
- [ ] Record host OS and Python version.
- [ ] Run the dry-run validator.
- [ ] Execute all five clean repetitions without editing the harness.
- [ ] Preserve all PASS, FAIL and AMBIGUOUS outcomes.
- [ ] Deposit raw result directories, source code, image identifiers and checksums.
- [ ] Report pilot results separately from confirmatory results.
- [ ] Do not describe H4 as proved; report support/falsification across tested mechanisms.
